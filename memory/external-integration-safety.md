# 外部集成安全边界

自动化 agent loop 不得在无人确认时使用真实账号凭据、真实 Cookie/token、生产数据库或生产级外部服务行为。

允许自动执行：

- 本地 fixture 测试
- 使用已提交脱敏 fixture 的解析测试
- 不打印密钥的配置形状校验
- 使用 fake/sanitized 输入的 worker 行为测试
- 只读本地文档和示例配置

必须人工确认：

- 真实账号登录
- 真实 Cookie/token/`.env` 访问
- 真实外部服务调用范围或频率变更
- 可能触发账号、计费、合规风险的动作
- 提交任何可能包含密钥的文件
- 生产环境或付费外部服务运行
